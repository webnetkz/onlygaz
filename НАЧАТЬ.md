# Veyron Sim — собранный проект

Все исходники, модель Bugatti, 22 текстуры, звук двигателя и последние правки
находятся в этой папке. Дополнительно распаковывать старые архивы не нужно.

## Запуск на Mac

Откройте `Запустить Veyron.command` двойным щелчком. Скрипт перейдёт в папку
проекта, соберёт актуальную release-версию и запустит игру. Нужен установленный
Rust 1.95 или новее; при первой сборке на другом компьютере понадобится интернет
для загрузки зависимостей.

У актуальной оптимизированной версии в заголовке окна указано
`[EXTREME NITRO BOOST 2026-09-10]`. Если этой метки нет, открыта другая копия игры.

Либо откройте терминал в этой папке и выполните:

```sh
cargo run --release --locked
```

По умолчанию игра запускается в быстром режиме. Более тяжёлые варианты освещения:

```sh
VEYRON_QUALITY=balanced cargo run --release --locked
VEYRON_QUALITY=cinematic cargo run --release --locked
```

## Управление

| Клавиша | Действие |
| --- | --- |
| W / S | Газ / тормоз, удержание S на месте — задний ход |
| A / D | Поворот |
| Пробел | Ручной тормоз |
| Левый / правый Shift | Экстремальное нитро и синий огонь из выхлопа |
| C | Следующая камера |
| R | Вернуть машину на дорогу |
| B | Задний вид |
| F7 / F8 | Мощность x3 / включить или выключить ABS |
| M | Включить / выключить звук двигателя |
| F3 / F4 | Телеметрия / отображение физики |
| F5 | Переключить качество освещения |
| Esc, затем Q | Пауза, затем выход |

В меню паузы (`Esc`) качество графики можно изменить мышью:

- `PERFORMANCE` — целевые 60–120 FPS;
- `BALANCED` — качественная картинка и умеренная нагрузка;
- `CINEMATIC` — прежняя картинка максимального качества со всеми эффектами.

Настройка применяется сразу, перезапуск игры не нужен.

На клавиатуре Mac для функциональных клавиш может потребоваться Fn.

Подробности проекта — в `README.md`, состав объединённой версии и результаты
проверки — в `docs/assembly-report.md`.
